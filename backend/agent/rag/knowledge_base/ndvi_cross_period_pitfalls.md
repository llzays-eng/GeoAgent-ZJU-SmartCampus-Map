# 为什么 NDVI / RSEI 不能跨年份直接比较

这是遥感生态分析里最容易被忽略、但对结论正确性影响最大的一个方法论问题。

## 大气条件差异

不同期影像的大气校正精度不同：气溶胶含量、水汽含量、云污染程度都会
影响传感器接收到的反射率数值，即使地表植被状态完全没变，大气条件不同
也会让反演出的NDVI/RSEI数值产生系统性偏差。如果两期数据的大气校正方法
或校正质量不一致，直接相减比较，测到的可能是"大气差异"而不是"地表变化"。

## 物候期错位

同一区域、不同年份，如果选取的观测时间点不是严格对齐的物候期（比如
一期用了5月数据，另一期用了7月数据），季节性的植被生长差异会被误读成
年际变化。规范做法是固定同一时间窗口（比如都取6-9月生长季均值），
本项目 `ndvi_trend` 工具的 GEE 分支就是这样处理的（按生长季筛选后取均值）。

## 传感器差异

跨年份的长时间序列分析经常需要拼接不同传感器/不同代次卫星的数据
（比如Landsat不同代际之间，或MODIS与Landsat之间），不同传感器的
光谱响应曲线、空间分辨率、辐射定标标准都不完全一致，直接拼接比较
容易引入"伪趋势"——数值变化其实来自传感器切换，而不是地表真实变化。

## RSEI 的特殊性：PCA 主成分依赖具体影像

RSEI（遥感生态指数）通过对多个指标（一般包括绿度NDVI、湿度、干度、
热度）做主成分分析（PCA）合成一个综合指数。PCA的主成分是针对
"当次输入的这组影像"计算出来的——换句话说，不同年份分别做PCA得到的
主成分权重系数并不是同一套系数，两期RSEI数值即使数字看起来接近，
背后每个分量的权重贡献可能完全不同，直接比较绝对数值的意义有限，
更严谨的做法是要么用同一套主成分系数重新投影所有年份的数据，要么
只比较相对排序/等级变化，而不是比较原始PCA得分的绝对差值。

## 实践建议

- 只在同一物候期窗口内比较；
- 尽量使用同一传感器/同一处理流程产出的数据；
- 涉及PCA合成指标（如RSEI）时，明确说明多期数据是否共享同一套主成分权重；
- 报告趋势时同时报告数据来源、时间窗口和处理流程的一致性说明，而不是
  只给一个"从0.4涨到0.5"的数字。
