# NDVI（归一化植被指数）：定义、取值范围与常见误用

`ndvi_trend` 工具返回的核心数值就是 NDVI，这里是它的基础定义，供 RAG
检索"NDVI是什么意思"这类问题时使用（区别于工具调用——工具返回数字，
这篇文档负责解释这些数字代表什么）。

## 定义

NDVI = (NIR − Red) / (NIR + Red)

其中 NIR 是近红外波段反射率，Red 是红光波段反射率。健康植被对近红外光
强烈反射、对红光强烈吸收（用于光合作用），因此 NIR-Red 的差值越大、
NDVI越高，代表植被覆盖度/长势越好。

## 取值范围与含义

- 理论范围 [-1, 1]；
- 水体、云、雪：通常为负值或接近0（水体对近红外几乎不反射）；
- 裸地、建成区、道路：通常在 0~0.2 之间；
- 稀疏植被/草地：通常在 0.2~0.4 之间；
- 茂密植被（森林、生长旺盛的作物）：通常在 0.5 以上，很少超过0.9。

`ndvi_trend` 工具的 synthetic_demo 分支生成的数值控制在 0.05~0.95 区间，
是为了落在物理上合理的范围内，但请注意——那是模拟数据，仅用于演示
Agent的工具调用流程，不代表任何真实观测。

## 常见误用

1. **把NDVI当作"绿化率"直接使用**：NDVI反映的是植被的光谱响应强度，
   与人类定义的"绿化覆盖率"（某种规划/统计口径下的百分比）并不是同一个
   量，两者相关但不能划等号，不能说"NDVI从0.4涨到0.5就是绿化率涨了
   10个百分点"。
2. **忽略季节/物候期影响就下结论**：同一片区域，NDVI会随季节大幅波动
   （比如落叶林冬天NDVI远低于夏天），跨季节比较必须先明确是否使用了
   同一物候期的数据（比如都取生长季均值），否则季节差异会被误读成
   "植被退化"或"植被恢复"。
3. **单点/单期数据就判断趋势**：NDVI受大气条件、云污染、传感器角度等
   噪声影响，单次观测有波动是正常的，判断"趋势"需要足够长的时间序列
   和适当的统计方法，不能凭两个时间点的差值就下"显著变化"的结论——
   本项目的 `ndvi_trend` 工具明确不做显著性检验，只做首尾年份的简单比较，
   这一点在工具返回结果里也有说明。
