# RSEI 遥感生态指数：构成与 PCA 方法说明

RSEI（Remote Sensing based Ecological Index）是徐涵秋2013年提出的
综合生态质量评价指数，思路是把多个反映生态状况的单一指标合成为一个
可比较的综合分数，避免只看单一指标（比如只看NDVI）以偏概全。

## 四个基础指标

1. **绿度（Greenness）**：通常用NDVI表征，反映植被覆盖状况；
2. **湿度（Wetness）**：通常用缨帽变换（Tasseled Cap Transformation）
   的湿度分量表征，反映地表水分/土壤湿度状况；
3. **干度（Dryness）**：通常用建筑指数（IBI）与裸土指数（SI）的
   综合表征，反映不透水面/裸露地表程度；
4. **热度（Heat）**：通常用地表温度（LST，Land Surface Temperature）表征，
   反映热岛效应强弱。

## 为什么要用 PCA 合成

这四个指标量纲不同（NDVI是无量纲比值，LST是温度，湿度干度指数各有
自己的取值范围），不能直接加权平均。PCA（主成分分析）把四个标准化后
的指标投影到主成分空间，取信息量最大的第一主成分（PC1）作为RSEI的
基础，再做归一化处理，得到最终的RSEI值（一般归一化到0~1，越接近1
生态质量越好）。

选择PC1而不是其他主成分的原因：PC1通常能解释四个指标中最大比例的
总方差，且实践中PC1的载荷方向一般表现为"绿度、湿度为正贡献，干度、
热度为负贡献"，与生态质量评价的直觉一致（不需要额外做符号翻转的情况
更常见，但仍需要每次实际检查载荷方向，不能想当然）。

## 应用中的关键注意事项

- 四个基础指标在参与PCA之前必须先标准化（去量纲），否则数值范围大的
  指标会主导主成分方向；
- 如前一篇文档所述，PC1的载荷系数是针对当次输入影像计算出来的，
  不同期数据分别做PCA得到的系数并不通用，跨期比较RSEI绝对值需要谨慎；
- RSEI适合做区域内的横向比较（比如同一期影像下，校园东区和西区谁的
  生态质量分数更高），跨年份纵向比较需要按上一篇文档的方法论谨慎处理；
- 本项目当前的 `ndvi_trend` 工具是"精简版"，只做NDVI单指标查询，
  没有实现完整的四指标RSEI合成流程——这是有意识的范围裁剪（外
  部大纲里称为"精简版"），完整RSEI实现是后续可扩展的方向，不在
  当前GeoAgent的工具集里。
